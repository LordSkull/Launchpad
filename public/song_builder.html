Launchpad — Add Song

Choose an existing Launchpad-format ZIP, map its MP3 samples to the 48 pads of each chain, then export song.json. The Ruby installer validates and installs it without manual edits to keyboard.js.

Optional. One group per line. Use pad labels, separated by commas. Example: 1,Q,A,Z. When one pad in a group plays, the others are stopped.

4. Validate and export

Configure the song, then validate.

Then run from the Launchpad repo:

bundle _1.17.3_ exec ruby script/song_tool.rb validate C:\path\song.json C:\path\sounds.zip
bundle _1.17.3_ exec ruby script/song_tool.rb install  C:\path\song.json C:\path\sounds.zip
